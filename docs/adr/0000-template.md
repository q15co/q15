# Short title of the decision, in the present tense

Status: proposed

One to three sentences: what the context was, what was decided, and why. If the decision rests on a
measurement, state the measurement and the method. An ADR can be this short; the value is in
recording that a decision was made and what made it, not in filling out sections named below.

## Considered options

- Only when the rejected alternatives are worth remembering six months from now.

## Consequences

- Only when the downstream effect is not obvious from the decision itself.

Evidence: the files, and the issue or pull request the decision came from.
